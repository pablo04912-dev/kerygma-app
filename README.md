# KERYGMA App

Prototype de l'appli de l'église Kerygma (Paris) pour centraliser les plannings des ministères : qui sert quand, dans quel lieu, avec rappels.

**Essayer le prototype sur téléphone :** https://LIEN-GITHUB-PAGES (mis à jour automatiquement après chaque envoi)

> Toutes les personnes dans ce prototype sont inventées. Aucune vraie donnée de l'église n'est dans ce dépôt.

## Travailler sur le projet

- Première fois : suis `docs/demarrage.md`.
- Chaque séance : ouvre le dépôt avec Claude ; il lit `CLAUDE.md`, récupère le travail de l'autre et te le résume.
- Commandes : `npm install`, `npm run build`, `npm test`.

## Organisation

| Où | Quoi |
|---|---|
| GitHub (ce dépôt, public) | Le prototype, les tests, le journal, les règles pour Claude |
| Drive partagé "Kerygma App" (privé) | Le cadrage avec les vrais noms, les vraies données, les retours des commissions, les sauvegardes |

L'historique de GitHub garde toutes les versions : on peut revenir à n'importe quel état du projet.
